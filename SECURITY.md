# Security Policy

## Supported Versions

This project is actively maintained on the default branch (`master`) and via open pull requests.

| Version/Branch | Supported |
| --- | --- |
| `master` | ✅ |
| older release branches/tags | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for suspected vulnerabilities.

Instead, report privately by emailing: **security@william64.com**

If email is unavailable, open a private security advisory in GitHub:
- Go to **Security** tab → **Advisories** → **Report a vulnerability**

Please include:
- Affected component/file
- Reproduction steps or proof of concept
- Impact assessment (funds risk, auth bypass, data exposure, etc.)
- Suggested remediation (if available)

## Response Expectations

- Initial acknowledgement: **within 72 hours**
- Triage decision: **within 7 days**
- Fix/mitigation target: based on severity and exploitability

High-severity issues affecting contract funds or private keys are prioritized immediately.

## Disclosure Process

After remediation and deployment, maintainers may disclose details publicly with credit (if desired) to the reporter.
